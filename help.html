Nodemura Visual Composer Help

Welcome to the visual patcher for Hydra Live Coding. This tool allows you to create complex visual synthesizers using a node-based interface.

How does it work

This tool is a visual patcher for Hydra Live Coding. It creates animated visuals that can react to Audio, Video, Webcam, Screen capture, Midi, LFO and more.

To create a patch, start with a Source or External Source node. To add a node, you can double click with left mouse button over the canvas or click on the Add Node (+) button.

A patch must start with a Source or External Source node and end with a Output node. The Render node is a special node that accepts a node as input and outputs the result to the screen. If no nodes are connected to the Render node, it will output a maximum of four Output nodes (o0-o3).

Connect nodes by dragging the output socket of one node to the input socket of another node. Click on a node connector (dot) and drag towards another node connector (dot). You will see a line connecting the two nodes.

There are two kind of input/output connectors (dots): Nodes Connectors (orange=output and green=input) and Parameters Connectors (blue). Node connectors are used to connect nodes, while parameters connectors are used to connect parameters.

You can connect a Source node to a Geometry node to move or transform the node position or size. You can then connect to a Color node to change the Color of the node. You can connect to a Blend node to transform the node based on another Source node. The Blend node accepts a parameter (blue dot). You can connect a Source node to it. The connected source node can have other nodes attached, to create complex patches.

Click on a node to open the parameters windows on the right of the screen. Here you can modify the parameters of the node.

Data nodes are special nodes that generate content based on audio, video, webcam, screen capture, midi, lfo, array and more. They are not directly connected to any node, but they can be selected as a parameter value (right of the screen). When you connect a Data node to another node, you will see a dashed grey line connecting the two nodes.

When you are ready, you can test your patch by clicking the PLAY button.

You can SAVE your patch by clicking the SAVE button or export it as a JSON file clicking the EXPORT button. You can also load saved patches clicking the LOAD button. All patches are public and can be shared with other users.

Interface Controls

  • Canvas Navigation: Hold Middle Mouse Button or Space + Left Drag to Pan. Scroll to Zoom.
  • Add Node: Click the Add Node (+) button or Double-Click on the canvas.
  • Selection: Click a node to select. Shift + Click to select multiple.
  • Box Selection: Hold Right Mouse Button and drag to select multiple nodes.
  • Delete: Select node(s) and press Delete or Backspace.

Toolbar Buttons

  • New: Reset the canvas and start a fresh project.
  • Save: Save preset to database (requires login).
  • Load: Load preset from database.
  • Export: Download your patch as a .json file.
  • Import: Load a patch from a .json file.
  • Settings: Configure global BPM and speed.

  • Add Node (+): Open node library.
  • Scenes: NEW Open the Scenes management panel.

Scenes & Transitions NEW

Create multi-scene performances with automated transitions between visual patches.

Scenes Panel

  • Open Panel: Click the Scenes button in the toolbar. The panel is draggable!
  • Add Scene: Click + ADD SCENE to create a new scene from the current canvas state.
  • Select Scene: Click on a scene to load it into the editor.
  • Reorder Scenes: Drag and drop scenes to change playback order.
  • Delete Scene: Click the X button on a scene to remove it.

Scene Properties

Click on a scene name to expand its properties:

  • Duration: How long the scene plays (in seconds, minutes, beats, or MIDI trigger) before transitioning to the next.
  • Repeat: Number of times to repeat the scene before moving on.
  • Follow (Next Scene): Where to go after the repetitions (next scene, previous, first, last, random, none).
  • Transition In: Effect used when entering this scene.
  • Transition Duration: How long the transition animation takes (in milliseconds).
  • MIDI Trigger: Channel and Note to trigger this scene via MIDI.

Transition Types

  • Crossfade: Simple opacity blend between scenes.
  • Fade to Black: Fades out to black, then fades in the new scene.
  • Wipe (Horizontal): Horizontal wipe from left to right.
  • Wipe (Vertical): Vertical wipe from top to bottom.
  • Radial: Circular reveal from center.
  • Glitch: Digital glitch effect with horizontal displacement.
  • Zoom: Zoom-in transition with bloom effect.
  • Pixelate: Pixelation effect during transition.
  • Melt: Luminance-based distortion effect.

MIDI Scene Triggers

Trigger scenes in real-time using MIDI notes:

  1. Open a scene's properties in the Scenes panel.
  2. Select a MIDI Channel (1-16 or All).
  3. Set a MIDI CC (0-127) and a MIDI CC Value (0-127) to trigger the scene.
  4. During playback, send the corresponding MIDI CC on your MIDI controller!

User Account System NEW

Create an account to save and manage your patches in the cloud.

Registration

Click the Register button in the top-right corner to create a new account. Fill in the following fields:

  • First Name: Your first name (required).
  • Last Name: Your last name (required).
  • Nickname: Your display name visible to others (required).
  • Email: Your email address for login (required).
  • Password: Minimum 6 characters (required).
  • Confirm Password: Re-enter password to confirm (required).

Alternatively, click Continue with Google to register using your Google account.

Login & Profile

  • Login: Access your account using email/password or Google authentication.
  • Profile: Once logged in, your nickname is displayed in the header. Click on it to edit your profile or logout.
  • Edit Profile: Update your name, nickname, or password anytime.
  • Logout: Click on your nickname and select Logout to sign out.

Recording Settings NEW

Record your visual patches as video files. Access these settings from Settings → Recording Settings.

  • FPS: Frame rate for recording. Choose between 30 FPS or 60 FPS (best effort, depends on system performance).
  • Video Format: Select the output format:
    • WebM (VP9) - Best quality, widely supported.
    • WebM (VP8) - Good compatibility, smaller files.
    • MP4 (H.264) - Best for sharing (browser support varies).
    • MP4 (H.265/HEVC) - High compression, excellent quality (limited browser support).
  • Quality: Bitrate slider from 2 Mbps to 100 Mbps (lossless). Higher values = better quality, larger files.
  • Record Audio: Enable to include audio in the recording.
  • Audio Input Device: Select the microphone or audio interface to record from.
  • Audio Volume: Adjust the gain from 0% to 200%.

Tip: Press the RECORD button next to PLAY to start recording. A timer will appear in the top corner during recording.

Patch Title & Update NEW

The patch title is displayed in the header next to the logo.

  • View Title: The current patch name appears in the top-left area of the interface.
  • Update Title: Click directly on the patch name to edit it. Press Enter to confirm or Escape to cancel.
  • Unsaved Indicator: An asterisk (*) appears next to the title when you have unsaved changes.
  • Quick Update: If you're the owner of a loaded patch, clicking on the title and changing it will update the patch name on the server when you save.

Node Types

Sources

Generators that start a chain. Examples: osc (Oscillator), shape, noise, voronoi, gradient, solid.

External Source NEW

Load external media into source buffers (s0-s3):

  • Local Image/Video: Select a file from your computer.
  • Remote Image: Load image from URL.
  • Webcam: Use your camera as input (select device from dropdown).
  • Screen: Capture your screen.
  • NOTE: An External Source node MUST be connected to a Source Input node. Then the Source Input node can be connected to any other node in the chain, or to an output node.

Geometry

Transformers that alter the coordinate space. Examples: rotate, scale, kaleid, pixelate, repeat, scroll.

Color

Modifiers for pixel colors. Examples: posterize, invert, contrast, brightness, saturate, hue, colorama.

Blend

Combine two textures. These nodes have a Main Input (background) and an Image Input (foreground). Examples: blend, add, diff, mask, mult.

Modulate

Use texture luminosity to deform coordinates. Examples: modulate, modulateRotate, modulateScale, modulateKaleid.

Data Nodes

Array Nodes

Create lists of values to sequence parameters.

  1. Add an Array node (under "Data" category).
  2. Add values using the + button.
  3. On target nodes, change parameter mode to "Node List" and select your Array.
  4. Dashed Lines will appear to show implicit connections.

Options: fit (BPM sync), smooth, fast, ease (easing function).

LFO Nodes

Low Frequency Oscillators for continuous modulation.

  • Frequency: Speed of oscillation.
  • Measure: Hz (cycles/sec), Seconds, or Frames (BPM synced).
  • Waveforms: Sine, Square, Sawtooth, Triangle, Pulse.
  • Pulse Width: Adjust duty cycle for Pulse waves.
  • Range: Output value range [min, max].

MIDI Nodes NEW

Receive MIDI input to control parameters in real-time.

  • Port: Select MIDI input device.
  • Channel: MIDI channel (1-16 or All).
  • Track: Data type - Note Number, Velocity, Aftertouch, Pitch Bend, CC, Program Change.
  • CC Number: Control Change number (0-127) when Track = CC.
  • Transpose: Map input to output range [min, max].

Tip: The node displays live values during playback!

Audio Nodes UPDATED

Analyze audio for reactive visuals (powered by Meyda).

  • Source: Choose between:
    • Audio Input - Use microphone or audio interface
    • File - Load a local audio file (.mp3, .wav, etc.)
  • Track: Audio feature to analyze (see table below)
  • Adaptive Range: NEW Auto-adjust input range if values exceed it
  • Input Range: Initial min/max for the selected track
  • Transpose: Map audio values to output range

Adaptive Range NEW

Some audio features don't have fixed ranges (e.g., rms, loudness). The Adaptive Range option automatically expands the input range if values exceed it during playback.

  • Enabled: Range expands to fit actual audio values. Good for unknown audio sources.
  • Disabled: Values are clamped to specified range. Good for consistent, predictable behavior.

Tip: Start with Adaptive ON, observe the actual range, then set it manually for production patches.

Troubleshooting & Missing Resources NEW

When loading a patch (Preset or Local Storage), Nodemura automatically validates external resources (Files, Microphones, MIDI Ports).

  • Red "X" Icon: Indicates that a resource is missing or invalid on a specific node.
  • Error Messages: Select the node to see specific error details at the top of the Properties Drawer.
  • Resolution:
    • Missing File: The system cannot persist local files for security reasons. Re-select the file using the "Select Image/Video/Audio" button to fix.
    • Missing Device: If a MIDI or Audio device is unplugged or ID changed, select the correct device again from the dropdown list.
  • Persistence: Errors will persist (remain visible) until you manually resolve them, ensuring you don't miss broken parts of your patch.

Parameter Hints NEW

Hover over the ℹ️ icon next to any parameter to see its description and default value.

Global Settings

Click the Settings button to configure:

  • BPM: Beats Per Minute. Affects LFO measure='frames' and Array fit.
  • Speed: Global speed multiplier for all animations.

Shortcuts & Tips

  • Play/Compile: Press the big PLAY button to render your patch.
  • Live Values: MIDI and Audio nodes show real-time values during playback.
  • Implicit Connections: Use LFOs, Arrays, MIDI, and Audio nodes as parameters - dashed lines show connections.
  • Export/Import: Use Export to backup patches locally, Import to restore.
  • New Project: Clear the canvas deeply using the New button.
